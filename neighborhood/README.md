# Greenbox neighborhood

A small, playable browser neighborhood using the original cubic voxel environment and five Garden chibi characters. The player has six actual rigid GLB body parts; walking moves arms and legs around their exported pivots. Four local NPCs turn toward the player, share short conversations, and return nearby emoji reactions.

Open `/neighborhood/` on the Greenbox site. Move with WASD, arrow keys, or the visible direction pad. Walk up to a neighbor or the Night Market and press E or the interaction button. Drag the scene to orbit, scroll to zoom, or use the camera buttons. The mini-map tracks the player, neighbors, and market. Six shared palette choices recolor all voxel assets while protecting identity colors.

The Night Market is a fictional game exchange. Offer selection shows a preview; Confirm trade checks the player is still in market range, validates coins, stock and inventory, and commits one atomic local transaction. Cancel leaves the pocket unchanged. Start a fresh visit resets the player, cards, stock and game coins. No real payments, external chat, multiplayer, real-world trade, network storage, or cultivation instructions are included. Inventory stays in memory during the visit and resets on reload.

`scripts/build-neighborhood.mjs` bundles Three.js and original GLB bytes into `public/neighborhood/index.html`. It requires the existing `viewer/node_modules` dependencies and reads the checked `voxel_sources/neighborhood/game_layout.json`, five Garden cast GLBs, three voxel TCG card GLBs, and the shared palette catalog. The HTML needs no CDN or runtime asset fetches. It embeds a copy of the Three.js MIT license.

`scripts/verify-neighborhood.mjs` checks source-bound GLB and layout hashes, actual rigid part pivots, triangle counts, self-contained buffers/images, bundle syntax and meaningful pure-rule cases: normalized movement, wall sliding, terrain containment, nearby station ranges, out-of-range rejection, cancellation, atomic trade conservation, invalid trades and reset. The source asset pack has its own independent voxel-to-mesh verification; `validation.json` records the browser bundle and rule checks. Live browser interaction is verified separately by the coordinator.

`game-core.mjs` owns deterministic gameplay state. `neighborhood.js` owns input, rendering, dialogue and presentation. The environment and collectible geometry are original Greenbox assets from `voxel_sources/neighborhood` and `voxel_sources/collectibles`, with provenance, licenses and editable VOX sources retained there. Original plants use the previously documented CC0-derived source.

The authored layout retains its 0.24 m body-radius suggestion. Runtime collision instead derives the actual large cube-head footprint from each GLB's transformed position bounds: the player's horizontal rectangle rotates with heading and NPC blockers use a yaw-safe circumradius. A 1 cm margin prevents shared-face overlap. Heading changes happen immediately; a turn that would intersect a wall is deferred while the player can slide away. All neighbors and the market remain reachable with this larger envelope. Terrain-edge bounds contain the complete avatar footprint; the optional `walkArea` inset is not used because the source terrain is solid across its full bounds.
