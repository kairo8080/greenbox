# Source records

Neighbor Commons architecture, terrain, signs, trees, bench, lamps, flowers, market, box and card display props are original Greenbox voxel artwork created for this project. No external screenshot pixels, logos, branded collectible frames or game characters are included.

The reused potted plant foliage derives from **Cannabis plants**, by **Yughues / Nobiax**, under **CC0 1.0 Universal**. Creator page: https://opengameart.org/content/cannabis-plants. License: https://creativecommons.org/publicdomain/zero/1.0/.

The source archive `source_originals/original_CC0_Cannabis.7z`, the author's exact `readme.txt`, the derived `cannabis_leaf.vox` and `cannabis_leaf_provenance.json` are preserved byte-for-byte from the existing Greenbox library. The original file describes cannabis foliage as finite-thickness voxelization of the actual source texture alpha silhouette. Both potted plants reuse that existing occupied-cube geometry with exact colors, and only their integer placement changes. The Garden preview palette is a presentation remap.

CC0 requires no attribution; this record is retained for traceability. No real-world commerce system or information about illegal transactions is represented by the fictional Night Market prop.
