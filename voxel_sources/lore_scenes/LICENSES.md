# Source and license records

The architecture, lettering, decorative icons, new scene props and chibi character designs are original Greenbox project artwork. No additional license for these project files is invented by this pack; use the project's asset licensing terms when distributing them.

The existing plant foliage derives from **Cannabis plants**, by **Yughues / Nobiax**, released under **CC0 1.0 Universal**. The original author readme explicitly states CC0. The original archive, readme, derived editable leaf VOX and full transformation/provenance record are preserved in `source_originals/`.

- Original asset page: https://opengameart.org/content/cannabis-plants
- CC0 license: https://creativecommons.org/publicdomain/zero/1.0/
- Detailed byte hashes and transformation history: `source_originals/cannabis_leaf_provenance.json`

The Touryst is credited as broad visual inspiration at https://thetouryst.shinen.com/deluxe/. Its screenshots, game character assets, textures and other artwork are not included or copied. This reference does not provide a license to redistribute that game's artwork.
